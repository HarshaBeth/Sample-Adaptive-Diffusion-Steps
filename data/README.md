# Data Directory

This directory is intentionally kept empty in the GitHub repository.

The datasets used in this project are not committed because they are large and should be downloaded or prepared locally.

Expected local datasets include:

- `BSDS300/`
- `GoPro_dataset_custom/`
- `imagenet_subset/`
- `img_align_celeba/`

Large compressed dataset files such as `.zip`, `.tgz`, `.tar`, and `.tar.gz` are ignored by `.gitignore`.

A `.gitkeep` file is included so that this directory exists after cloning the repository.
